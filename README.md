# Privacy Policy for صَلِّ

Last Updated: June 2026

صَلِّ does not collect, store, transmit, sell, or share any personal user data.

All settings, including reminder preferences and prayer counts, are stored locally on the user's device using Chrome storage APIs and are not transmitted to any external server.

The extension does not track browsing activity, collect website content, access personal communications, or gather personally identifiable information.

If you have any questions regarding this privacy policy, please contact the developer.
